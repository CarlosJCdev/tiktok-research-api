# Privacy Policy

**Last updated:** March 2025

## Overview

This project is an educational and research-oriented data engineering initiative that analyzes publicly available TikTok content using the official TikTok Research API.

This project is not affiliated with TikTok.

---

## 1. Data Collection

This project collects only publicly available metadata provided through the TikTok Research API, including:

- Video IDs
- Video creation timestamps
- Engagement metrics (views, likes, comments, shares, favorites)
- Public hashtags
- Public usernames
- Region codes

No private data, direct messages, email addresses, phone numbers, or restricted user information is accessed or stored.

---

## 2. Purpose of Data Use

The collected data is used strictly for:

- Educational purposes
- Academic research
- Data engineering architecture demonstration
- Analytics modeling and trend analysis

This project does not use data for:
- Advertising
- Marketing automation
- User profiling
- Behavioral targeting
- Commercial resale

---

## 3. Data Storage and Security

All data collected is stored in controlled environments and used only for analytical and educational purposes.

Raw data is processed into aggregated metrics and trend analysis models.

---

## 4. Data Sharing

This project does not sell, distribute, or share raw data with third parties.

Only aggregated, anonymized insights may be used for educational demonstrations.

---

## 5. Compliance

This project complies with TikTok Developer Terms, TikTok Research API policies, and applicable data protection regulations.
